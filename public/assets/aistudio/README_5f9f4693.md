# + PLUSTV Android App (Kotlin + Media3 ExoPlayer)

Build your installable Android APK **without Android Studio** using free GitHub Actions:

1. Extract this ZIP on your PC or Phone.
2. Go to https://github.com/new and create a new repository (e.g., `plustv-android`).
3. Click **uploading an existing file**, upload ALL extracted files/folders (including the `.github` folder), and click **Commit changes**.
4. Open the **Actions** tab in your GitHub repository -> wait ~2 minutes for **Build PlusTV Android APK** to turn green -> click it -> download **PlusTV-Debug-APK** -> extract `app-debug.apk` and install on your Android phone!

All channels (`jiotvmblive` _MOB + `jiotvpllive` _BTS + ClearKey DRM) play directly using native Media3 ExoPlayer and your phone's Indian network IP.
